### How to update this manifest

New reports live in `.github/reports/<workflow-type>/` (`bug-fix/`, `new-feature/`, `refactor/`, `unit-test/`, `code-review/`, `jira-ticket-investigate/`).

After adding or removing reports, add one row per report file (link: `<workflow-type>/<file>` for active, `archive/YYYY-MM/<file>` for archived), then re-sort: `bash .github/hooks/check-refs.sh --fix-manifest`. Verify with `bash .github/hooks/check-refs.sh`.

Lifecycle: `active` on creation → `archived` when moved from `<workflow-type>/` to `.github/reports/archive/YYYY-MM/` (post-merge, or the on-demand cleanup `bash .github/hooks/report-lifecycle.sh`, e.g. monthly or after merging to main, for stale reports: age = last git commit date, fallback mtime, default older than 30 days) → row removed when archived file older than 90 days is deleted (same entrypoint). Legacy equivalents: `legacy-active` → `legacy-archived`.
